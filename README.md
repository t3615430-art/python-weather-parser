# Python Weather Parser

Console weather app that fetches real-time data for any city.

## Features
- Temperature and feels like
- Weather description
- Humidity and wind speed

## How to run
pip install requests
python weather.py

## Example
Enter city: Kyiv
🌍 Weather in Kyiv:
🌡️ Temperature: 8°C
💨 Wind: 33 km/h
